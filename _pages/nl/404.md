<h2>
  <span id="missing-url">Deze pagina</span> bestaat niet.
</h2>

De pagina die je zoekt, is mogelijk verplaatst, hernoemd of niet langer beschikbaar.

[Terug naar startpagina]({{ '/' | relative_url }}){: .btn .btn--primary}

<script>
document.addEventListener("DOMContentLoaded", function () {
  var params = new URLSearchParams(window.location.search);
  var missing = params.get("missing");

  if (missing) {
    document.getElementById("missing-url").textContent =
      window.location.host + missing;
  }
});
</script>
